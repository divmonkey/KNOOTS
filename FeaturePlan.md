# KNOOTS Feature Expansion: AI Prompt Blocks (Multi-Tone Outputs)

Proposed extensions to expand the current multi-tone AI prompt options (which currently only generate LinkedIn, X/Twitter, and Threads variants) to support a wider array of content formats:

## 1. Professional Email / Newsletter (Substack)
*   **Format:** Paragraph layout with a clear subject line and formatted body sections.
*   **Tone:** Informative, value-driven, and authoritative.
*   **Structure:**
    *   Subject Line options
    *   Greeting and Hook
    *   Core takeaway
    *   Call-to-action (CTA)

## 2. Short Blog Post / Medium Draft
*   **Format:** A 3-paragraph expander.
*   **Tone:** Educational, professional, and structured.
*   **Structure:**
    *   **Introduction:** Explaining the problem or raw thought.
    *   **Body:** Context, details, and solutions.
    *   **Conclusion:** Summary of lessons learned.

## 3. Instagram Caption
*   **Format:** Visual-first spacing, line breaks, and emojis.
*   **Tone:** Highly engaging and conversational.
*   **Structure:**
    *   Hook sentence
    *   Bulleted key points separated by clean spacing
    *   Call-to-action (e.g., "Link in bio", "Let me know below")
    *   Tailored hashtag suggestions

## 4. Reddit Discussion Starter
*   **Format:** Thread-starter structure (Title + Text Body).
*   **Tone:** Conversational, critical, and community-focused.
*   **Structure:**
    *   Catchy Reddit title (e.g. "Am I the only one who thinks...")
    *   Flesh out thoughts with raw, honest details
    *   End with an open-ended question to generate comments (e.g. "What do you all think?")

## 5. TL;DR / Quick Summary
*   **Format:** Concise bullet points.
*   **Tone:** Direct, plain, and information-dense.
*   **Structure:**
    *   One-sentence summary
    *   3 key takeaway bullet points

## 6. Video Script Outline (TikTok / Reels / Shorts)
*   **Format:** Vertical video narrative script structure.
*   **Tone:** High-energy, engaging, and paced.
*   **Structure:**
    *   **0-3s (Hook):** Catchy starting sentence
    *   **3-30s (Concept):** Step-by-step raw verbal details
    *   **30-40s (Outro):** Fast call-to-action
